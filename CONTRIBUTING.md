# Contributing to EduGenius Mobile

We're excited that you're interested in contributing to EduGenius Mobile! Before you begin, please take a moment to read the following guidelines.

## Code of Conduct

This project adheres to the [Contributor Covenant Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.

## How to Contribute

### Reporting Bugs

1. Check if the bug has already been reported in the [issues](https://github.com/syed-mujtaba-stack/edugeniusmobile/issues).
2. If not, create a new issue with a clear title and description.
3. Include steps to reproduce the bug and any relevant screenshots or error messages.

### Suggesting Enhancements

1. Check if the enhancement has already been suggested.
2. Create a new issue describing the enhancement and why it would be useful.
3. Include any relevant screenshots or mockups.

### Making Changes

1. Fork the repository and create a new branch for your feature or bugfix.
2. Make your changes following the project's coding standards.
3. Write tests for your changes.
4. Ensure all tests pass.
5. Submit a pull request with a clear description of your changes.

## Development Setup

### Prerequisites

- Node.js (v16 or later)
- npm or yarn
- Expo CLI
- MongoDB (for backend development)

### Installation

1. Fork and clone the repository
2. Install dependencies:
   ```bash
   # Frontend
   npm install
   
   # Backend
   cd server
   npm install
   ```

### Coding Standards

- Follow the existing code style
- Write meaningful commit messages
- Add comments for complex logic
- Keep the code clean and maintainable

## Pull Request Process

1. Ensure any install or build dependencies are removed before the end of the layer when doing a build.
2. Update the README.md with details of changes to the interface.
3. Increase the version numbers in any example files and the README.md to the new version that this Pull Request would represent.
4. The project maintainers will review your Pull Request and may suggest changes.

## Questions?

If you have any questions, feel free to open an issue or contact the maintainers.
